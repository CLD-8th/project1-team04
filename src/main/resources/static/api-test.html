Project 1 · API console

중고거래 API 테스트

계정을 만든 뒤 판매자와 구매자로 로그인하고, 상품 등록부터 거래 승인까지 한 화면에서 확인합니다.

API 10개상품·거래·계정실제 서버 응답
중고거래 사이트 API 테스트

요청에 사용할 계정

판매자와 구매자 계정을 한 번씩 로그인하면 두 화면에서 공유합니다. 접근 토큰은 발급 후 최대 30분간 유효합니다.

판매자 · 로그인 전 구매자 · 로그인 전

1. 계정

회원가입 후 역할을 선택해 로그인하세요.

FR-10POST

회원가입

/api/users

테스트에 사용할 판매자·구매자 계정을 만듭니다.

요청 전

FR-08POST

로그인

/api/users/login

로그인할 역할을 선택하면 해당 세션에 접근 토큰을 보관합니다.

요청 전

FR-09POST

로그아웃

/api/users/logout

현재 계정의 접근 토큰을 서버에서 무효화하고 화면의 로그인 정보를 지웁니다.

요청 전

2. 상품

등록 결과의 상품 ID가 아래 입력란에 자동으로 채워집니다.

FR-01POST

상품 등록

/api/products

판매자 계정을 선택하고 PNG 또는 JPEG 사진을 첨부하세요.

요청 전

FR-02GET

상품 목록

/api/products

현재 API는 전체 목록을 반환합니다. 문서의 카테고리·상태 필터는 아직 구현되지 않았습니다.

요청 전

FR-05GET

상품 상세

/api/products/{productId}

상품 ID로 상태와 판매자 정보를 확인합니다.

요청 전

FR-07GET

최근 본 상품

/api/products/recent

현재 계정으로 본 상품을 최근 순서대로 최대 20개 조회합니다.

요청 전

3. 거래

구매자가 신청하고 판매자가 목록 확인 후 승인합니다.

FR-03POST

거래 신청

/api/products/{productId}/application

구매자 계정을 선택하세요. 성공하면 거래 ID가 자동 입력됩니다.

요청 전

FR-06GET

신청 목록

/api/products/{productId}/deals

판매자 계정으로 해당 상품의 신청을 조회합니다.

요청 전

FR-04POST

거래 승인

/api/deals/{dealId}/approve

판매자 계정을 선택한 뒤 신청 목록의 거래 ID를 승인합니다.

요청 전

최근 API 응답

상태 코드와 서버가 반환한 내용을 그대로 확인하세요. 로그인 토큰 값은 표시하지 않습니다.

대기 요청 전
아직 요청하지 않았습니다.
왼쪽에서 API를 선택해 실행하세요.
요청 오류도 실제 응답으로 표시합니다. 로그인은 토큰 만료 전까지 두 화면에서 공유됩니다.
